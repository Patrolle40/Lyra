Questions & answers

Good to know.

What is Lyra?

Lyra is an Android-focused timed lyrics editor for creating and adjusting synchronized lyrics.

Can I edit word-by-word timing?

Yes. Lyra includes a word-by-word editing workflow.

Is there a public APK download yet?

The official download URL has not been configured on this demo website. It can be added without changing the page design.

Can another app integrate with Lyra?

Lyra has an Android import integration concept. See the Import V1 developer documentation; verify its sample code before production use.

Will old versions remain available?

The planned release structure keeps version-specific release links while this website highlights only the latest public version.
