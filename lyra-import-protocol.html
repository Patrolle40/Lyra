Lyra Import Protocol v1

Compatible apps use offline Android Intents and Activity Results. No internet is required.

Exported Activity

<activity android:name=".LyraExportActivity" android:exported="true">
  <intent-filter>
    <action android:name="com.lyra.app.action.PICK_SONG" />
    <category android:name="android.intent.category.DEFAULT" />
  </intent-filter>
</activity>

Return audio URI

Intent result = new Intent();
result.setData(audioUri);
result.putExtra(Intent.EXTRA_STREAM, audioUri);
result.setClipData(ClipData.newUri(getContentResolver(), "Audio", audioUri));
result.addFlags(Intent.FLAG_GRANT_READ_URI_PERMISSION);
setResult(Activity.RESULT_OK, result);
finish();

Use a valid content URI accessible to Lyra, from Android's file picker or FileProvider. On cancel, return RESULT_CANCELED.

A successful connection test only detects the action, not a complete audio transfer.
